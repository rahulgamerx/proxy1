# RGX Tactical Console

Mobile-responsive static demo dashboard with a tactical gaming-console aesthetic.

**Important:** All statuses, ping, region node, and logs are fictional/local demo values. It does not connect to Free Fire or verify actual game features.

## Deploy on Vercel
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of a GitHub repository.
3. Import that repository at https://vercel.com/new
4. Choose **Other** as framework preset. Leave build command empty; deploy as a static site.
